# User-approved design workflow

- Before applying any new or revised app or home-screen widget design, show the user a visual preview and wait for explicit approval of that preview.
- Build an APK only after the user has seen and approved the corresponding design. Do not enable APK builds triggered automatically by source pushes.
- Preserve vehicle ordering and branch grouping, return-date blinking, A/S and insurance expiry warnings, and existing vehicle actions unless the user explicitly requests changing them.
- Use clearly labelled synthetic data for design previews. Do not copy real fleet data into a mockup.
