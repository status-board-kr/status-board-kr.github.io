# 장성현황판 안드로이드 앱 만들기 (백그라운드 위치 공유 포함)

플레이스토어에 올리지 않고, **설치파일(APK)을 직접 폰에 설치**해서 쓰는 방식입니다.
그래서 구글 심사가 필요 없어요.

> 연결된 Firebase 프로젝트: **fleet-board-f2345** (ss20100579@gmail.com 계정)

---

## 0. 한 번만 설치 (컴퓨터)

1. **Node.js 20 이상** — https://nodejs.org 에서 "LTS" 받아 설치
2. **Android Studio** — https://developer.android.com/studio 에서 받아 설치
   (설치 중 옵션은 전부 기본값. 처음 실행하면 SDK를 추가로 받는데 끝까지 기다리세요)

---

## 1. 프로젝트 준비

이 폴더(`장성현황판-앱`)에서 **주소창에 `cmd` 입력 후 엔터** → 검은 창이 열립니다. 아래를 한 줄씩 입력:

```
npm install
npm run setup
```

`npm run setup`이 알아서 해주는 것:
- 안드로이드 프로젝트 생성
- 위치·알림 권한 추가, 상단 알림 아이콘 설정
- 앱 아이콘 생성
- 화면 파일 반영

---

## 2. 설치파일(APK) 만들기

```
npm run open
```
→ Android Studio가 열립니다. 아래쪽 진행 막대가 끝날 때까지 기다리세요 (처음엔 몇 분 걸림).

메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
→ 끝나면 오른쪽 아래 알림의 **locate** 클릭 → `app-debug.apk` 파일이 나옵니다.

---

## 3. 폰에 설치 (직원 폰마다)

1. `app-debug.apk`를 카톡 "나와의 채팅" 등으로 폰에 보내기
2. 폰에서 파일 누르기 → "출처를 알 수 없는 앱" 경고 → **설정에서 허용** → 설치
3. 앱 실행 → 로그인

---

## 4. ⚠️ 폰 설정 (이거 안 하면 백그라운드가 꺼집니다)

앱에서 📍 동료위치보기 → 동의 → 위치 권한을 물어보면:

1. **위치 권한**: "앱 사용 중에만 허용" 선택 (앱이 상단 알림으로 계속 실행되므로 이걸로 충분)
2. **알림 권한**: "허용" — 이게 있어야 상단에 "위치 공유 중" 알림이 뜨고, 그래야 안드로이드가 앱을 안 끕니다
3. **배터리 최적화 해제 (삼성폰은 필수!)**
   설정 → 애플리케이션 → 장성현황판 → 배터리 → **"제한 없음"**
   (삼성은 이걸 안 하면 몇 시간 뒤 앱을 강제로 재워서 위치가 멈춥니다)

정상이면 휴대폰 상단에 **"위치 공유 중"** 알림이 떠 있고, 앱을 닫아도 유지됩니다. 공유 시간이 끝나면 자동으로 사라집니다.

**공유 시간 바꾸기 (관리자만)**: 📍 동료위치보기 → ⚙️ 위치 공유 시간에서 시작/종료 시각 입력 → 저장.
바꾸면 모든 직원이 새 시간으로 **다시 동의**해야 공유가 재개됩니다. 밤샘(예: 20:00~06:00)도 됩니다.

https://localhost

## 6. 계기판 사진으로 회수 처리 (주행거리 자동 인식)

채팅에서 **📷 버튼 → 계기판 사진 찍기 → "9588 회수" 입력 → 전송**
→ AI가 누적 주행거리(ODO)를 읽어서 **"37,622 km 맞나요?"** 하고 물어봅니다
→ 맞으면 확인, 틀리면 숫자 고쳐서 확인
→ 차량이 회수 처리되고, **결제일 알림 → 청구 미완료** 목록에 회수 시간·종료 주행거리·계기판 사진이 남습니다

**자동 인식을 쓰려면 AI API 키가 필요해요 — 구글 Gemini(무료 사용량 있음) 추천**
1. https://aistudio.google.com 에서 API 키 발급
2. **관리자 폰**에서 메신저 위쪽 **🤖 AI 설정** → 키 붙여넣기 — **한 번만 넣으면 모든 직원 폰에 자동 적용**돼요 (Claude 키 `sk-ant-…`도 됨)
   - 직원은 키를 볼 수는 있어도 바꾸거나 지울 수는 없어요 (관리자만)
3. 번호 없이 **"조완 보험 윤상"**, **"회수"** 처럼만 써도 사진 속 번호판을 읽어서 "105하9585 맞나요?" 물어봅니다
4. **피해차량(상대 차량) 사진을 같이 올리면**, 우리 차량이 아닌 번호판은 **메모 맨 뒤에 자동으로 붙습니다**
   (예: "조완 보험 윤상" → 메모 `윤상 12가3456`). 회수 기록·차량 이력에도 상대차량 번호가 남아요
- Gemini 무료 사용분은 구글이 서비스 개선에 쓸 수 있다고 안내하고 있어요 (계기판·번호판 사진 정도는 괜찮은 수준)
- 구글이 바쁠 땐 자동으로 다른 모델로 다시 시도합니다

- 키는 **그 휴대폰에만 저장**되고 서버·코드에는 올라가지 않아요. 폰마다 따로 넣어야 해요
- 키가 없어도 회수는 되고, 주행거리만 직접 입력하면 됩니다
- AI가 잘못 읽을 수 있으니 확인창에서 꼭 숫자를 한 번 보세요

## 화면(HTML)을 고쳤을 때

`www` 폴더의 파일을 바꾼 뒤:
```
npm run sync
```
→ 2번(APK 만들기)부터 다시. 직원 폰에도 새 APK를 다시 설치해야 반영됩니다.

## 동작 방식 요약

| 상황 | 동작 |
|---|---|
| 공유 시간(기본 09~18시, 관리자가 변경) + 동의함 | 앱을 닫거나 화면을 꺼도 계속 공유, 상단에 알림 표시 |
| 30m 이상 이동 | 즉시 저장 |
| 제자리 | 5분마다 "살아있음" 저장 |
| 공유 시간 종료 | 자동 종료 + 내 위치 삭제 |
| 직접 끄기 | 즉시 종료 + 삭제, 그날은 다시 안 켜짐 |
| 폰 꺼짐 / 신호 없음 | 동료 화면에 ⚪ "마지막 위치 N분 전"으로 표시 |
