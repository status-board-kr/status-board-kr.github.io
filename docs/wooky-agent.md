# 면허증 찍으면 우기 계약서 자동 작성

손님이 차를 받으러 오면 직원이 폰으로 면허증을 찍어 올리고, 사무실 PC가 우기 임대차계약서를 대신 채워요.
우기는 사무실 PC에서만 열리기 때문에, 사무실 PC 크롬에 작은 프로그램(확장 프로그램)을 깔아서 씁니다.

| 파일 | 역할 |
|---|---|
| `contract.html` | 직원용 화면. 면허증 촬영 → AI가 글자 읽기 → 차량·기간 고르기 → 사무실 PC로 보내기 |
| `wooky-agent/` | 사무실 PC 크롬 확장 프로그램. 30초마다 현황판을 보고 우기 계약서를 채움 |

## 흐름

1. 직원: `https://status-board-kr.github.io/contract.html` 에 현황판 계정으로 로그인
2. [📷 면허증 찍기] → AI가 이름·생년월일·주소·면허번호·면허 종류·유효기간을 읽어요. 노란 칸은 직접 확인
3. 확정 예약을 누르거나(고객 문의 채팅 예약이 있을 때), 차량·출발·반납을 고르고 휴대폰을 넣어요
4. [🖨 우기에 계약서 쓰기] → `companies/{업체}/wooky/jobs` 에 작업이 들어가요
5. 사무실 PC 확장 프로그램이 우기에서 [대여관리 → 임대차 계약서]를 열고 칸을 채우고, [차량조회]에서 차량을 골라요
6. **채우기만** 모드: 노란 칸을 직원이 확인하고 [저장(F2)]. **저장까지 자동** 모드: 빈칸이 없을 때만 저장

- 면허증 사진은 어디에도 저장하지 않아요. 읽은 글자만 작업에 담기고, 사무실 PC가 다 쓰면 작업에서 지워요 (이름·차량번호·결과만 남음).
- 주민등록번호는 생년월일만 읽어요.
- 우기 계약서 창이 열려 있으면(직원이 다른 계약서를 쓰는 중) 닫힐 때까지 기다려요.

## 사무실 PC 설치 (한 번만)

1. `wooky-agent` 폴더를 사무실 PC에 받아 둡니다
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `wooky-agent` 폴더 선택
4. 크롬 오른쪽 위 퍼즐 조각 → **팡팡 우기 자동입력** → 현황판 이메일·비밀번호로 **연결하기** (비밀번호는 저장하지 않음)
5. 우기에 로그인해 두고 **가짜 손님으로 시험** → 우기 계약서가 채워지면 성공 (저장은 안 함)

사무실 PC 크롬이 켜져 있고 우기에 로그인돼 있어야 해요. 직원 화면 맨 위에 "사무실 PC 연결됨"이 보이면 정상이에요.

## 필요한 것

- 현황판 **🤖 AI 설정**의 키 (Claude 키 권장, Gemini 키도 동작)
- Realtime Database 보안 규칙에서 업체 멤버가 `companies/{업체}/wooky` 를 읽고 쓸 수 있어야 해요
