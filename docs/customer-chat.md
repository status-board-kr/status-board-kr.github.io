# 고객 문의 채팅 설치 방법

고객이 링크로 들어와서 "카니발 이번 주말 돼요?"라고 물으면, 현황판 차량 현황을 보고 AI가 바로 답해줍니다.
예약을 원하는 고객은 채팅에서 바로 예약 신청을 하고, 그 신청은 **현황판 일정에 "📅 예약요청"으로 자동 등록**돼요.
새 예약·상담 요청이 들어오면 **현황판 직원 채팅에 알림 메시지**가 올라오고 **직원 폰(앱)으로 푸시**가 가요.
예약을 **확정·차량 변경·날짜 변경·취소**할 때도 직원 채팅에 "✅ 예약 확정: 카니발 10/3 10시 ~ 10/5 18시 · 차량 34나1111 · 홍길동 010-…" 같은 기록이 남아요.
관리 화면에서 **확정**을 누르고 **차량을 고르면**, 일정 제목이 "✅ 예약확정 10/3 10시 ~ 10/5 18시 카니발(34나1111) · 홍길동"으로 바뀌고 **현황판 그 차량 카드 오른쪽 끝에 "📅 예약 10/3 10시 ~ 10/5 18시"**가 떠요. **취소**를 누르면 일정과 표시가 모두 지워져요.
AI는 이미 잡힌 예약 기간도 보고 가능 여부를 답해요.
장기렌트·견적처럼 날짜가 안 정해진 문의는 AI가 **대화로 상담 신청**을 받아요(따로 신청서는 없어요). 단기/장기, 기간, 시작 시기, 희망 차종, **예산**, 지역, 이름, 연락처, 생년월일, 요청사항을 하나씩 물어보고, 접수 직전에 **이벤트 문자 수신 동의**를 한 번 물어봐요. 접수하면 현황판 일정 "📝 상담신청 …", 직원 메신저·폰 알림, **고객 명단 시트**로 들어가요.
날짜가 바뀌거나 연장하면 관리 화면의 **날짜 변경**으로 고치세요. 일정 날짜·제목과 차량 카드 표시가 같이 바뀌어요. 차량 카드의 "예약" 표시는 **대여 시작 전까지만** 나오고, 출고 후에는 평소처럼 현황판 반납일자로 관리하면 돼요. 고객이 채팅으로 연장을 요청하면 AI가 상담 요청으로 넘겨요.

| 파일 | 역할 |
|---|---|
| `chat.html` | 고객용 채팅 페이지 |
| `inquiry-admin.html` | 사장님용 관리 화면 (설정, 링크, 상담 요청, 대화 기록) |
| `pangcar/index.html` | 팡팡렌트카 홈페이지 (AI 상담 버튼, 신청서 없음) |
| `docs/customer-sheet.gs` | 고객 명단 구글 시트에 붙여넣는 스크립트 |
| `functions/` | 서버 (Firebase Cloud Functions). `answer.js`가 모든 채널이 같이 쓰는 AI 답변·예약·상담 신청 접수 로직 |

**고객에게 나가는 정보**: 차종별 가능 여부("가능해요 / 그 날짜는 어려워요"), 관리 화면에 직접 적은 가격·업체 안내. 보유 대수는 말하지 않아요.
**나가지 않는 정보**: 차량번호, 고객 이름, 계약 금액, 입금 여부, 메모, 직원 정보.

## 홈페이지 (`pangcar/`)

예전 팡팡렌트카 홈페이지 내용(라인업·가격, 대여 절차, 서비스 지역)을 옮기고, **상담 신청서는 없앴어요.**
- **AI 실시간 상담 버튼**: 누르면 AI 채팅 창이 열려요. 예약 신청과 상담 신청을 대화로 받아요.
- **"상담 신청" 칸**(예전 `#form` 주소 그대로): 신청서 대신 "💬 AI 상담으로 신청하기"와 "📞 전화로 상담하기" 버튼이 있어요.
- AI가 받은 상담 신청은 현황판 **일정(오늘 날짜, "📝 상담신청 장기 12개월 소형 SUV · 홍길동")**, **직원 메신저**, **직원 폰 알림**, **고객 명단 시트**로 가요. 관리 화면 "예약·상담 요청"에서도 볼 수 있어요.
- 예전 홈페이지가 쓰던 본사 구글 시트로는 **보내지 않아요.** 아래 "고객 명단 구글 시트"로 사장님 전용 시트를 만들어 연결하세요.

차량 보유 대수는 홈페이지와 AI 상담 어디에도 나오지 않아요. AI는 "가능해요 / 그 날짜는 어려워요"까지만 말해요.

켜려면 `pangcar/index.html` 맨 위 `companyId`에 업체 ID를 넣으세요. 관리 화면 "고객에게 보낼 링크"의 `?c=` 뒤 값이에요. 비워두면 AI 버튼이 숨겨지고 전화 상담 버튼만 보여요.
주소는 `https://status-board-kr.github.io/pangcar/` 예요. 예전 주소(pang-rent.github.io/pangcar)로 옮기려면 이 파일을 그 저장소에 복사하고 `chatPage`를 `https://status-board-kr.github.io/chat.html`로 바꾸면 돼요.

## 1. Firebase 요금제 확인 (한 번만)

서버 기능(Cloud Functions)은 Blaze(종량제) 요금제에서만 쓸 수 있어요. 이미 직원 채팅 푸시 서버(`sendChatPush`)를 쓰고 계셔서 **Blaze일 가능성이 높아요**. [Firebase 콘솔](https://console.firebase.google.com/project/fleet-board-f2345/usage/details)에서 확인만 해주세요.

이 배포는 `inquiry`라는 별도 묶음(codebase)으로 올라가서, 기존 `sendChatPush` 같은 다른 서버 기능은 **건드리지 않아요**.

## 2. 배포 키 등록 (한 번만)

1. Firebase 콘솔 → ⚙ 프로젝트 설정 → **서비스 계정** → "새 비공개 키 생성" → JSON 파일 다운로드
2. [Google Cloud IAM](https://console.cloud.google.com/iam-admin/iam?project=fleet-board-f2345)에서 그 서비스 계정(`firebase-adminsdk-…`)에 역할 추가:
   **Firebase 관리자**, **서비스 계정 사용자**, **Cloud Functions 관리자**
3. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret
   이름 `FIREBASE_SERVICE_ACCOUNT`, 값은 JSON 파일 내용 전체

## 3. 서버 배포

GitHub 저장소 → **Actions** → "고객 문의 채팅 서버 배포" → **Run workflow**.
초록색 체크가 뜨면 끝이에요. `functions/` 코드를 고쳤을 때만 다시 실행하면 됩니다.

## 4. AI 키 확인

현황판의 **🤖 AI 설정**에 넣어둔 키를 그대로 써요. **Gemini 키**면 Gemini(현황판 사진 인식과 같은 무료 모델)로, Claude 키(`sk-ant-`로 시작)면 Claude로 답해요.
무료 Gemini는 구글이 대화 내용을 서비스 개선에 쓸 수 있어요. 고객 이름·연락처가 오가니, 손님이 많아지면 구글 AI Studio에서 결제를 켜는 걸 추천해요(결제를 켜면 대화 내용을 학습에 쓰지 않아요).

## 5. 켜기

1. `https://status-board-kr.github.io/inquiry-admin.html` 에 현황판 대표 계정으로 로그인
2. **가격 안내**, **업체 안내**(영업시간·위치·조건)를 적고 **고객 문의 채팅 켜기** 체크 → 저장
3. 위쪽 **고객에게 보낼 링크**를 복사해서
   - 당근 비즈프로필 → 자동응답 문구에 "차량 현황은 여기서 바로 답변드려요 👉 (링크)"
   - 인스타 프로필 링크, 인스타 자동응답(빠른 답장)에도 같은 링크

## 6. 고객 명단 구글 시트 (이벤트 문자용)

AI 상담으로 받은 상담 신청과 예약 요청이 사장님 구글 시트에 한 줄씩 쌓여요. **"문자동의명단"** 탭에는 이벤트 문자 수신에 동의한 분의 이름·연락처만 자동으로 모여요. 이벤트·광고 문자는 **동의한 분께만** 보내야 해요(정보통신망법).

1. [sheets.new](https://sheets.new) 에서 새 구글 시트를 만들고 이름을 "팡팡렌트카 고객명단"처럼 바꿔요
2. 메뉴 **확장 프로그램 → Apps Script** → 있던 코드를 지우고 `docs/customer-sheet.gs` 내용을 통째로 붙여넣고 💾 저장
3. 오른쪽 위 **배포 → 새 배포** → ⚙에서 유형 **웹 앱** 선택
   - 실행: **나**, 액세스 권한: **모든 사용자** → **배포** → 권한 검토에서 본인 구글 계정으로 허용
   ("확인되지 않은 앱" 화면이 나오면 고급 → 이동 누르기. 사장님이 직접 만든 스크립트라서 나오는 안내예요)
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사
5. 관리 화면 → **고객 명단 시트 주소**에 붙여넣고 **연결 확인** → ✓ 뜨면 **저장**

시트 칸: 접수 시각 · 경로(AI상담) · 구분(상담신청/예약요청) · 대여 유형 · 기간 · 시작 시기 · 희망 차종 · 예산 · 지역 · 이름 · 연락처 · 생년월일 · 요청 · 이벤트 문자 동의.
시트 저장이 실패해도 접수는 현황판에 그대로 남고, 관리 화면에 "시트 저장 실패"로 표시돼요.
시트 주소는 누구나 한 줄 추가할 수 있는 주소라서 **관리 화면에만 넣고 밖에 공유하지 마세요.** (홈페이지 코드에는 들어가지 않아요)

## 요금

- Gemini 키: 무료 모델(`gemini-3.1-flash-lite` 등, 현황판 사진 인식과 같은 목록)을 먼저 쓰고, 바쁘면 다음 모델로 넘어가요. 무료 사용량을 넘으면 그날은 답이 늦거나 "잠시 후 다시"가 나올 수 있어요.
- Claude 키: 답변 한 번에 몇 원 수준 (`claude-sonnet-5`)
- 관리 화면의 **하루 최대 답변 수**(기본 300)를 넘으면 그날은 "전화로 문의해주세요"로 안내해서 요금이 튀지 않아요.

## 참고

- 데이터 위치: `companies/{업체ID}/customerChat/` 아래 `settings`, `leads`(예약·상담 요청), `sessions`(대화), `usage`(일별 사용량). 예약 요청·상담 신청은 `companies/{업체ID}/schedules`에도 들어가요.
- 푸시는 직원이 앱에서 알림을 켜둔 경우(`members/{uid}/pushToken`)에만 가요.
- 관리 화면에서 설정 저장이 실패하면 Firebase Realtime Database 보안 규칙이 `companies/{업체ID}` 아래 쓰기를 막고 있는 경우예요. 업체 멤버가 `customerChat` 을 읽고 쓸 수 있게 규칙을 확인해주세요.
