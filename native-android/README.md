# 현황판 전용 안드로이드 앱 전환

현재 상태: 데이터 계층 초안과 화면 시안. 실행 가능한 앱/APK가 아니며 Kotlin 코드는 아직 컴파일하지 않았다.

화면은 Kotlin / Jetpack Compose로 구현한다. WebView로 기존 HTML을 띄우는 앱으로 만들지 않는다. PC 웹은 별도로 유지하고 Firebase의 기존 업체별 데이터와 인증을 재사용한다.

## 적용 전 확인

- 시안 승인 후 화면 구현 및 수동 APK 빌드. 기존 배포 빌드 작업은 그대로 둔다.
- 기존 패키지명·서명키 및 위젯 provider 이름을 유지할 때 업데이트 설치가 가능하다. 기존 WebView 로그인 세션의 native Auth 이전은 별도 확인하며 필요하면 재로그인한다.
- 실제 폰에서 최초 실행·다시 열기·사진 1장/여러 장 시간을 비교하기 전에는 성능 개선치를 단정하지 않는다.

## 옮겨야 하는 기능

1. 로그인, 업체 가입/초대, 관리자/직원 권한, 퇴사자 접근 해제.
2. 차량 목록, 기존 지점/수동 순서, 필터 전체·대기·준비중·보험·일반·장기, 차량 상세/편집, 회수 임박 표시.
3. 보험·A/S·검사·차령 경고와 확인 처리, 배차/회수 실행 기록 및 재배차 건수.
4. 일정, 반복 일정, 완료/수정, 차량 반납 일정 연동, 기존 알림 예약/푸시.
5. 메신저, 사진 압축/저장, AI 번호판·주행거리 판독, 조완/ㅈㅇ/회수/ㅎㅅ 명령, 상대 차량 메모.
6. 우기소프트 일꾼 상태/종결 재시도. PC 일꾼은 별도 프로그램으로 유지.
7. 기존형·간편형 위젯, 간편형 날짜 일정 팝업, 장성군 날씨.
8. 위치 공유 및 동의. 휴일 기준과 매일 재동의 여부는 아직 사용자 답변이 필요.
9. 관리자 설정, 직원 관리, 사진 등록/엑셀, 변경 기록, 수납/계약서 등 현재 기능 전수 비교.

`core`는 인증 확인 후 업체/사용자별 캐시를 읽고 서버 결과로 갱신하는 데이터 계약 초안이다. Firebase 어댑터, 화면, 위젯/알림/위치 연결 및 빌드 설정은 아직 구현 전이다. 전체 차량 배열을 캐시에서 그대로 덮어쓰는 편집은 금지하며, 원본 필드는 변환 과정에서 보존한다.
