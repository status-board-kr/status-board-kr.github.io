# 현황판 전용 Android 앱

기존 웹 현황판의 디자인·배열·업무 기능을 Kotlin/Compose로 이전한다. WebView는 사용하지 않는다. PC 웹/기존 업무 앱은 유지하고 시험판 com.jangsung.fleet.nativepilot은 별도 설치된다. 회사별 Firebase 자료와 계정은 공유한다.

2026-10-03 사용자 지시: 전체 기능 이전을 먼저 완료하고 통합 검증·수정을 진행한다. 화면별 미세 디자인 수정과 반복 APK 발행은 미룬다. 기존 승인된 배열·위젯을 사용하며 신규 디자인은 먼저 보여주고 승인받는다. APK 자동 빌드는 사용하지 않는다.

0.1.0 검증 APK가 공개되어 있고, 중복 메뉴 정리 0.1.1 빌드는 Actions 37107303563에서 성공했다. 현재 추가 기능은 코드 검사 단계이며 전체 완성본/실제 휴대전화 검증 완료를 의미하지 않는다.

## 이전 현황

- 로그인·회사 권한, 암호화 캐시, 실시간 차량/일정/메신저, 원본 차량 순서/지점/필터/색상/회수 깜빡임.
- 배차/회수/재배차 건수, 사진 압축·전송/AI/상대차량 메모, 주행거리 수정, PC 일꾼 상태/실패 재시도.
- 일정 추가·수정·완료·삭제, 반복 일정, 기본 차량 편집.
- 구현·코드 검사: 두 위젯, 간편형 홈 일정 팝업, 장성군 날씨, 직원 이름·권한·내보내기·초대, 이전 대화/전체 검색/백업/삭제.
- 구현·코드 검사: 가입·초대 가입, 차량 수동·CSV/XLSX·등록증 사진 등록, 삭제/차령·검사 계산, 회사·AI·개인 설정, 변경 기록·차량 되돌리기.
- 구현·코드 검사: 장기 결제 안내/계좌/발송 표시·기록, 일반 매출·연장·입금·고객 편집, 회수·미청구/수동 기록. 실제 문자·카카오 전송은 사용자가 외부 앱에서 실행한다.
- 구현·코드 검사: 기존 여섯 문서의 항목/계산/저장/견적→계약 전환, 신차 가격·렌트 계산 기준, PDF/미리보기/인쇄/JPG 공유, 상담 연락 처리.
- 구현·코드 검사: 회수·결제·미청구·근무 시작 로컬 알림, 별도 Android FCM 등록/메신저·상담 경로, 직원 위치 동의·근무시간 GPS 서비스, 위젯 백그라운드 갱신.
- 통합 검증 중: 현재 Firebase 규칙의 가상 DB 검사, 추가 알림/발송 기록 저장 처리. 운영 규칙은 변경하지 않는다. 전체 기능 실기기 검증과 승인 후 새 APK 발행이 남아 있다.

직원 지도는 현재 지도 앱으로 좌표를 여는 방식이다. 문서는 원본 항목 순서를 유지하되 PDF의 표 배치는 별도 네이티브 출력이다. 웹과 화면을 완전히 동일하게 검증했다고 표현하지 않는다. 이전 0.1.0/0.1.1 APK에는 새 기능 전체가 포함되어 있지 않다.

## 저장과 재시도

회사 소속은 Auth UID → userIndex → 서버 members로 확인한 뒤 노출한다. 캐시는 UID+회사별 AndroidKeyStore AES-GCM, 백업 제외, 로그아웃/접근 해제 때 제거한다. Firebase 보안 규칙을 약화시키지 않는다.

명령은 서버 차량 트랜잭션과 _nativeOperations 후속 기록을 사용한다. PC가 완료한 종결 요청은 초기화하지 않는다. 수동 편집은 _nativeEdits에 매출/일정 후속 저장을 기록하고, 연장은 요청 id별 한 번만 반영한다. 캐시 전체 차량 배열로 서버를 덮어쓰지 않는다.

## 유지 정책

- 전체·대기·준비중·보험·일반·장기 순서와 지점 묶음, 보험/A/S/검사/차령 경고 유지.
- 같은 차량 회수 후 재배차는 새 배차 건수. 조완/ㅈㅇ 모두 인식.
- 주행거리 없이도 종결 요청. 입고자 자동 입력 없음.
- 기존형 날짜 클릭은 위젯 내부 선택, 간편형은 홈 화면 위 일정 팝업.
- 위치: 관리자 제외, 토·일·공휴일/업무시간 밖 제외. 최초 동의 유지, 철회/OS 권한 해제 때 근무 중 재안내. 검증된 연도별 휴일 자료가 없으면 수집하지 않는다.

## 개발 검사

JDK 17, SDK 35, Gradle 8.11.1. 공개 Firebase 설정/AI 모델·프롬프트만 빌드 때 준비하며 서버 키·직원 비밀번호는 넣지 않는다.

```sh
node scripts/prepare-client.cjs
gradle :app:compileDebugKotlin :app:compileDebugJavaWithJavac :app:testDebugUnitTest :app:lintDebug
```

scripts/prepare-widgets.cjs는 기존 승인된 위젯 원본을 시험판 네이티브 패키지로 복제한다. 생성 결과는 소스에 포함하며 기존 웹/Capacitor 앱은 수정하지 않는다. 코드 검사 workflow는 APK를 발행하지 않는다. 전체 출시 검증 조건은 docs/RELEASE-GATES.md에 기록한다.
