# 현황판 전용 앱 통합 검증 준비

승인한 통합 화면으로 0.2.2-pilot (versionCode 5)을 빌드한다. 파일: status-board-native-pilot-0.2.2.apk. 기존 공개 0.1.0 및 앞서 만든 0.1.1과 현재 소스의 기능 범위는 다르다.
앱 이름: 현황판 전용앱 시험판
패키지: com.jangsung.fleet.nativepilot

기존 웹 기반 앱(com.jangsung.fleet)을 삭제하지 않고 함께 설치한다. 기존 앱 및 위젯을 대체하는 업데이트가 아니다. Android 8.0 이상이 필요하다. 개발용 서명이며 정식 배포용 서명과 구별한다.

## 데이터와 현재 범위

기존 계정으로 로그인하며 실제 회사 Firebase를 공유한다. 메신저 전송, 일정 저장 및 회수·배차 명령은 실제 업무 데이터에 반영된다. 확인용 문자를 보내더라도 차량번호와 회수·배차 명령을 함께 적으면 명령이 실행된다. 사진 AI는 실제 호출 비용이 생길 수 있다.

현재 소스의 확인 범위는 로그인/가입/초대, 차량/등록/편집/관리/삭제, 배차·회수·사진 명령, 일정, 직원/설정/변경 기록, 일반 매출/장기 결제/회수·미청구, 여섯 문서 및 상담이다. 문서는 PDF/JPG 공유와 인쇄까지 연결한다. 직원 위치는 앱 안의 지도와 직원 목록에서 확인한다. 지도 부분은 기존 웹의 카카오 지도를 그대로 사용하고 위치 수신·인증·저장은 네이티브에서 처리한다.

현재 소스는 알림 권한을 요청하며 FCM과 로컬 알림, 기존형/간편형 위젯, 직원 위치 동의와 GPS가 구현되어 있다. 위치는 관리자·주말·공휴일·근무시간 밖에는 수집하지 않는다. 최초 동의를 유지하며 해제한 직원만 근무 중 다시 안내한다. 새 통합 APK의 실제 기기 검증 전까지 기존 앱을 유지한다.

## 휴대폰 확인 순서

1. 기존 현황판 앱을 그대로 두고 APK를 별도 설치한다. ‘현황판 전용앱 시험판’이 따로 생기는지 확인한다.
2. 기존 계정으로 로그인해 올바른 회사·직원 권한인지 확인한다. 최초 로그인, 재실행 속도를 각각 확인한다.
3. 기존 앱과 차량 지점·순서·메모를 비교한다. 전체/대기/준비중/보험/일반/장기 필터, 회수 임박 깜빡임, A/S·보험·검사·차령 경고를 비교한다. 동일 차량의 회수 후 재배차를 각각 세는지 실제 업무에서 확인한다.
4. 날짜를 눌러 일정이 나오는지, 메신저 대화·사진이 보이는지, 사진 확대·키보드·닫기·뒤로가기가 정상인지 확인한다. 회사 업무용 일정은 삭제 테스트에 사용하지 않는다.
5. 실제 전송 확인이 필요하면 차량 명령 없는 ‘전용 앱 연결 확인’ 같은 글 한 건으로 양쪽 메신저 동기화를 확인한다. 사진·회수·배차는 실제 업무를 수행할 때 확인한다.
6. 인터넷을 끊었다가 복구하고 앱을 다시 켜본다. 권한 해제·로그아웃 후 이전 회사 차량/사진/대화가 노출되는지 확인한다.
7. 기존형/간편형을 각각 추가하고 날짜 동작을 비교한다. 간편형은 앱 메인이 아닌 홈 위 일정 팝업이 열려야 한다. 장성군 예보, 재부팅 후 갱신을 확인한다.
8. 양쪽 앱의 알림을 허용한 직원 기기에서 실제 업무 대화/상담이 양쪽에 도착하는지 확인한다. 전용 앱에서 대화를 보는 동안 중복 알림이 없는지, 알림을 누르면 해당 대화/상담이 열리는지 확인한다.
9. 일반 직원은 근무시간에 최초 위치 동의/OS 권한을 확인한다. 동의 유지·철회·업무 종료·주말/공휴일과 관리자 제외를 확인한다. 테스트를 위해 실제 직원의 동의 상태를 임의로 변경하지 않는다.
10. 여섯 문서의 원본 항목·계산·저장, PDF/JPG/인쇄와 날짜/금액, 매출/입금/연장/회수·미청구를 실제 입력 전 가상 자료로 확인한다. 회사 변경 기록의 되돌리기와 전체 발송 기록 삭제는 실제 데이터로 시험하지 않는다.

기기 검증 결과는 기종, Android 버전, 어떤 화면에서 발생했는지, 기대 동작과 실제 동작을 함께 기록한다. 자동 검사는 컴파일·핵심 로직·Lint 기준이며 실기기 또는 실제 계약 종결 검증을 대신하지 않는다.

## 승인한 웹 배열과 화면 색상
상단 메뉴, 필터, 종결 봇 상태, 오늘 일정, 검색·정렬, 지점별 차량 카드와 우측 금액을 웹 배열에 맞춘다. 하단 메뉴는 제거한다. 설정 → 내 앱 설정 → 화면 색상에서 화이트/블랙을 선택하며 해당 휴대전화에 저장한다. 실제 휴대전화에서 글자 확대·좁은 화면·키보드와 각 업무 화면을 비교해야 한다.

## 0.2.2 위치 재검증
GPS 꺼짐, 권한 거부, 근무시간 제외, GPS 대기, Firebase 저장 실패를 구분해 표시한다. 첫 진입 시 현재 위치를 요청하며 최근 2분 이내 좌표만 저장한다. 저장 실패로 서비스를 즉시 종료하지 않는다. 지도에서 직원 위치를 선택하고 갱신 시간을 확인한다. 자동 검사는 실제 휴대전화의 GPS와 배터리 제한을 검증하지 않는다.
