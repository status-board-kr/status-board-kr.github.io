# 회사 맞춤 앱에서 출시 앱으로 전환

현재 소스에는 차량/메신저/일정, 등록/관리/직원/설정/변경 기록, 매출/수납/문서/상담, 두 위젯, 위치 동의/GPS와 알림이 연결되어 있다. 코드 검사 통과와 실제 휴대전화 동작 검증은 구별한다. 공개된 0.1.0 APK는 이 전체 기능 소스의 결과물이 아니며 업무용 배포 앱을 교체하지 않는다. 새 통합 APK는 화면 확인·승인 후 별도 발행한다.

## 업체 분리

- 소속은 Firebase Auth UID → userIndex → 회사 members의 서버 검증으로 결정한다. 회사명을 보고 업체를 선택하거나 회사 id를 상수로 지정하지 않는다.
- 캐시는 UID+회사별 분리, AndroidKeyStore AES-GCM 암호화, 백업 제외. 로그아웃/권한 해제 시 제거한다. 서버에서 권한을 확인하지 못하면 시작 단계에서 캐시를 노출하지 않는다.
- 기본 지점/장기 구분/회사 표시명은 profile에서 읽는다. 없는 값은 기존 차량 지점에서 추론하되 데이터베이스에 자동 저장하지 않는다. 향후 회사 설정 스키마를 실제 웹과 일치시킬 필요가 있다.
- Firebase 보안 규칙이 데이터 접근을 최종 결정한다. 클라이언트 역할 확인만으로 권한이 보장됐다고 판단하지 않는다. 출시 전 규칙 테스트/Emulator가 필요하다.

## 출시 전 통과 조건

1. 기존 앱 기능별 동작 비교: 차량 순서, 지점, 회수 경고, A/S/보험/검사/차령 경고, 배차 재출고 건수, 일반/보험/장기, 사진/상대 차량 메모, 금액, 계약서/변경 기록, 직원 권한.
2. 실제 기기: 낮은 사양 포함 최초 실행/재실행, 긴 목록, 사진 여러 장, 앱 재개, 화면 회전, 프로세스 종료, 통신 끊김, 업체 변경 및 퇴사자 접근.
3. 기존 앱 서명/패키지 및 widget provider 이름 호환, FCM token 이전, 알림 중복 방지, 일정 날짜 링크 및 홈 팝업, 캐시 이전/삭제.
4. 개인정보 처리방침 및 동의, 계정/회사 데이터 삭제 흐름, 보유 기간, 사진/GPS 목적과 수집 범위, 관리자 권한, 권한 철회, 휴일/업무 종료 처리. 현재 소스는 직원 최초 동의와 OS 권한, 검증된 휴일·근무시간 조건이 맞을 때만 위치 서비스를 시작한다. 0.1.0 공개 APK와 구별한다.
5. Play 등록 때 최신 target SDK 및 백그라운드 위치/사진 접근/알림 정책을 공식 문서로 재확인. 지금의 target 35 빌드 설정을 출시 기준으로 단정하지 않는다.
6. 스토어 배포용 서명/업로드키를 비공개로 보관, 테스트와 운영 환경 분리, AAB, 내부 테스트/점진 배포, 오류 대응 및 롤백 계획.
7. AI 서비스 키는 출시 전에 서버에서 보관/호출하도록 전환, 고객사별 사용량/오류/비용 제한 마련. 서비스 계정/관리자 키는 APK 또는 공개 저장소에 넣지 않는다.

## 아직 필요한 사용자 결정

- 위치 동의: 관리자는 제외, 토·일·공휴일 및 업무 시간 밖은 제외한다. 최초 동의는 유지하며 동의/OS 권한을 해제한 직원만 근무 시간에 다시 안내한다(2026-10-03 사용자 결정).
- 기존 웹 현황판의 업무 화면 디자인 및 배열을 전용 Android 화면으로 옮긴다. 새 밝은 업무 화면 시안은 거절됐다. 원본 웹 구조를 사용한 배열 시안은 2026-10-03 사용자에게 승인됐다.
- 승인된 배열에 과거 대화/검색/백업/사진 표시, 차량 관리 계산·삭제·등록, 일반 매출 및 자동 일정 후속 저장도 연결했다. 실제 회수·배차·문자 전송은 업무 데이터에 영향을 주므로 가상 검사와 실제 업무 확인을 구별한다.
- 검증한 2026/2027년 휴일 자료와 OS 권한/GPS 서비스가 연결되어 있다. 자료가 없는 연도에는 위치 수집을 시작하지 않는다. 실제 기기의 배터리 제한·서비스 종료·휴일/업무 종료 검증은 남아 있다.
- 직원/관리자 메뉴 화면은 2026-10-03 새 시안으로 승인됐다.
- 출시 앱에 포함할 계약서·수납 기능 범위, 가격/가입 정책은 향후 별도 결정.

## 회사 시험판 통합 확인 항목

- 간편형 위젯 날짜 → 홈 화면 일정 팝업, 기존형 날짜 → 위젯 내부 일정. 재부팅·프로세스 종료·로그아웃 후 소속 자료 제거.
- 기존 앱 pushToken을 전용 앱이 덮어쓰지 않음. nativePushTokens에 설치별 저장. 서버 sendchatpush/aiconsult는 기존 알림과 새 앱 알림을 따로 처리. FCM/실시간 중복과 채팅을 보는 동안의 알림 억제 확인.
- Emulator는 demo-native-fleet와 가상 회사만 사용. 실제 운영 권한의 읽기/쓰기 경로를 복사하여 테스트한다. wookyJobs의 공개 접근은 기존 PC 일꾼과 호환되는 현재 운영 규칙이며 출시 전 별도 인증 설계가 필요하다. 이 작업에서 권한을 넓히지 않는다.
- 날짜·차량 순서/지점/경고는 원본 대조. 직원 지도는 외부 지도 앱, 문서 PDF 표 배치는 네이티브 구현이므로 화면 차이를 확인한다.
